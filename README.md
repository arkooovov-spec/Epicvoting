# EuroVote — мобильный сайт голосования

## Что это
Готовый сайт голосования с интерфейсом, адаптированным в первую очередь для смартфонов. Включает:
- добавление стран, флагов (emoji или URL), песни и исполнителя;
- распределение 12, 10, 8, 7, 6, 5, 4, 3, 2 и 1 балла по 10 разным странам;
- таблицу результатов;
- открытие/закрытие голосования;
- экспорт/импорт данных JSON.

## Важно про ограничения
Это **локальная демо-версия**. Данные хранятся в `localStorage` конкретного браузера. Другие люди не увидят их голосов, а ограничение «один голос» можно обойти другим браузером/очисткой данных. Админка не защищена паролем. Не используйте эту сборку для публичного конкурса с реальными голосами без backend, общей базы данных, серверной проверки и авторизации администратора.

## Запуск — самый простой вариант
1. Распакуйте архив `eurovote-site.zip`.
2. Откройте папку `eurovote-site`.
3. Дважды нажмите `index.html`. Сайт откроется в браузере.
4. Перейдите в **Админка**, добавьте страны, флаги, песни и исполнителей.
5. Перейдите в **Голосование**. Выберите баллы сверху, затем нажмите на карточку страны/кнопку баллов. Повторите для 10 стран.
6. Нажмите **Отправить голос**.
7. Вкладка **Результаты** покажет сумму баллов.

## Запуск через локальный сервер (рекомендуется)
Если браузер ограничивает некоторые функции при открытии файла:
- Установите Python 3 с сайта https://www.python.org/downloads/ (при установке Windows отметьте Add Python to PATH).
- Откройте терминал/командную строку в папке проекта.
- Выполните:
  - Windows: `py -m http.server 8000`
  - macOS/Linux: `python3 -m http.server 8000`
- Откройте `http://localhost:8000`.

Остановить сервер: `Ctrl+C`.

## Как выложить в интернет (демо)
1. Создайте аккаунт GitHub и новый репозиторий.
2. Загрузите `index.html`, `style.css`, `app.js`.
3. В настройках репозитория откройте **Settings → Pages**.
4. В разделе Build and deployment выберите **Deploy from a branch**, ветку `main`, папку `/ (root)`, сохраните.
5. Через некоторое время GitHub Pages покажет публичный адрес сайта.

GitHub Pages публикует статические файлы. Она не предоставляет серверную базу голосов, поэтому голосование будет локальным у каждого посетителя.

## Как сделать настоящую общую голосовалку
Для реального публичного запуска потребуется:
- backend (например, Supabase/Firebase или собственный сервер);
- общая база стран и голосов;
- серверная проверка распределения баллов и закрытия голосования;
- аутентификация администратора;
- ограничение повторных голосов по учетной записи/приглашению. IP/device fingerprint не гарантируют уникального человека и могут затрагивать приватность.

## Структура
- `index.html` — страницы и элементы интерфейса
- `style.css` — внешний вид и адаптивная верстка
- `app.js` — голосование, результаты и админка
- `README.md` — инструкция


## Использование на телефоне
Откройте опубликованную ссылку в Safari или Chrome. Интерфейс адаптируется под экран смартфона: одна колонка карточек, крупные кнопки и нижняя панель отправки голоса. Для добавления на главный экран: iPhone — Поделиться → На экран «Домой»; Android/Chrome — меню ⋮ → Добавить на главный экран.
